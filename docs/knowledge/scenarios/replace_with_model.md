# Вставка модели для отображения на карте

 * Пользователь указывает адрес здания
 * Система обнаруживает это здание и если находит, наводит на него камеру
 * Пользователь указывает id всех полигонов, которые должны быть замещены указанной моделькой
 * По умолчанию модель позиционируется в место, где находится первая точка первого из полигонов
 * По умолчанию масштаб модели 1.0
 * Пользователь перемещает модель так, чтобы модель ровненько перекрывала замещаемые полигоны
 * Пользователь жмет кнопку "Сохранить", после этого:
 * Система загружает модель в хранилище
 * Система создает запись в таблице моделей, с id модели и урлом к загруженной в хранилище модели
 * Система сохраняет несколько записей, ставящих соответствие между полигонами и моделью
