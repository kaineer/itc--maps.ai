# Вставка модели для отображения на карте

## Обзор сценария
Процесс привязки 3D модели к одному или нескольким зданиям (полигонам) на карте.

## Поток пользователя

### 1. Инициация процесса
* Пользователь выбирает опцию "Добавить модель"
* Система предлагает ввести адрес основного здания

### 2. Поиск и позиционирование
* Пользователь указывает адрес здания
* Система обнаруживает это здание и наводит на него камеру
* Отображаются все здания в области видимости

### 3. Загрузка модели
* Пользователь загружает 3D модель (FBX, GLTF и др.)
* Система валидирует файл и показывает предпросмотр
* Модель временно позиционируется в центр первого найденного здания

### 4. Выбор связанных зданий
* Пользователь указывает ID всех полигонов, которые должны быть замещены указанной моделью
* **Важно**: Одна модель может замещать несколько зданий (полигонов)
* Система визуально выделяет выбранные здания
* Пользователь может добавлять/удалять здания из ассоциации

### 5. Начальное позиционирование
* По умолчанию модель позиционируется в место, где находится первая точка первого из полигонов
* По умолчанию масштаб модели 1.0
* Система показывает bounding box всех связанных зданий для ориентира

### 6. Выравнивание модели
* Пользователь перемещает, масштабирует и вращает модель
* Цель: модель должна ровненько перекрывать ВСЕ замещаемые полигоны
* Преобразования применяются ко всей группе связанных зданий одновременно
* Визуальная обратная связь показывает соответствие модели и полигонов

### 7. Сохранение конфигурации
* Пользователь жмет кнопку "Сохранить"
* Система выполняет следующие действия:
  * Загружает модель в хранилище
  * Создает запись в таблице моделей с ID модели и URL к загруженной модели
  * Сохраняет несколько записей, ставящих соответствие между ВСЕМИ выбранными полигонами и моделью
  * Сохраняет параметры выравнивания (позиция, масштаб, вращение) для модели

## Особенности многозданийности

### Визуальное представление
* Все связанные здания отображаются с одинаковой стилизацией
* При выборе одного здания группы - выделяются все связанные
* Bounding box показывает общую область всех связанных зданий

### Управление ассоциациями
* Возможность добавить новые здания к существующей модели
* Возможность удалить здание из ассоциации
* Предупреждения при конфликтах (когда здание уже связано с другой моделью)

### Технические аспекты
* Выравнивание применяется ко всей группе зданий
* Изменения позиции/масштаба/вращения влияют на все связанные здания
* Система должна обрабатывать сложные случаи (перекрывающиеся здания, иерархические структуры)

## Обработка ошибок
* Валидация формата 3D модели
* Проверка на достаточное пространство для модели
* Конфликт-детекция при перекрытии с существующими моделями
* Восстановление после прерванного процесса
