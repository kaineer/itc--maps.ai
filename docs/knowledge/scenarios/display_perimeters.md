# Рендер многоугольников через threejs

 * Клиент запрашивает полигоны, лежащие на указанном расстоянии от точки, в которой сейчас находится камера
 * Для каждого загруженного полигона в threejs рисуется полигон высотой H метров, где H - поле height для указанного полигона, полученного из открытых карт и основанием - отрезком между двумя последовательными точками этого полигона
 * (что по поводу зданий, загруженных через пользовательский интерфейс?)
