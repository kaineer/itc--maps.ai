## Компоненты

* Каждый компонент определяется внутри своего файла
* Компонент определяется как стрелочная функция, принимающая единственный параметр и возвращающая ReactNode
* Типы пропсов (и остальные типы, по возможности) объявляется, как interface, а не как type.


## Работа с данными

* данные, которые нужно хранить более, чем в одной форме, хранятся в слайсах
* для создания и использования слайсов используется @reduxjs/toolkit
* слайсы, подключенные в общий store экспортируются только как 

```ts
export const myDataSlice = createSlice({ ... })
```

* селекторы для получения данных из слайсов, определяются внутри createSlice({ ..., selectors: ... })
* получение селекторов и экшнов из импорта происходит так:

```ts
import { myDataSlice } from "path/to/slice/myDataSlice"

const { getDataValue } = myDataSlice.selectors;
```

* подключение редьюсеров внутри store/index.ts происходит через 

```ts
{ 
  [myDataSlice.reducerPath]: myDataSlice.reducer,
}
```
